# 音乐去噪任务参考

## 1. 任务目标

音乐去噪任务要求从带噪音频中去除噪声，尽量保留原始音乐或语音内容。学生需要理解音频信号的基本表示方式，选择合适的去噪方法，并通过试听、波形、频谱或指标展示去噪效果。

学生需要使用深度学习模型或预训练模型完成去噪任务，重点是完成可复现流程，并分析去噪前后声音质量的变化。

## 2. 输入与输出

典型输入：

- 带噪音频
- 干净音频，可选，用于计算指标

典型输出：

- 去噪后的音频

建议展示形式：

- 去噪前音频
- 去噪后音频
- 波形图对比
- 频谱图对比
- 定量指标表格

## 3. 示例数据准备

如果只有一段测试音频，也可以先完成最小样例：

1. 将测试音频保存为统一格式，例如 wav。
2. 记录采样率、声道数和时长。
3. 运行一个深度学习模型或预训练模型。
4. 对比去噪前后的听感、波形和频谱。

如果需要构造更多数据，可以使用干净音频和噪声音频进行混合，得到带噪样例。

建议样例数量：

- 基础展示：3 到 5 段音频
- 较完整实验：20 到 100 段音频
- 数据集实验：使用公开数据集中的子集

## 4. 数据集建议

助教仅提供固定验收测试音频 `test/raw.MP3`，该音频为带噪音频，没有对应的干净参考，主要用于最终主观听感和波形/频谱对比评价。

学生需要自行寻找合适的公开数据集用于训练和实验。数据集应包含 clean 和 noisy 成对音频，便于计算定量指标。如果没有成对数据，也可以自行将干净音频和噪声音频混合得到带噪样例，但报告中需要说明无法计算依赖 clean 参考的指标。

可选的公开数据集来源包括：

| 数据集 | 规模参考 | 适用说明 |
|---|---:|---|
| VoiceBank-DEMAND / Valentini Noisy Speech | test 约 310MB；28spk train clean+noisy 约 4.95GB | 经典 clean/noisy 成对语音增强数据 |
| Microsoft MS-SNSD | 可 sparse checkout 测试目录 | 语音降噪数据，可用 clean/noise 合成 noisy |
| Noisy Reverberant Speech Database | test 约 169MB；train1 约 2.716GB | 去噪/去混响任务数据 |
| GTZAN | 下载约 1.14GB，解压后约 3.7GB | 音乐片段数据，可作为干净音乐来源 |
| GTZAN Music/Speech | 下载约 283MB，解压后约 425MB | 小规模音乐/语音片段，适合快速实验 |
| ESC-50 | 约 770MB 到 900MB | 环境声音数据，可作为噪声来源 |
| Free Spoken Digit Dataset | 约 10MB 到 50MB | 小规模语音数据，适合快速验证语音去噪流程 |
| 自建小数据集 | 由学生控制 | 可用于补充展示，需要说明音频来源 |

使用扩展数据时需要在报告中注明来源、规模、采样率、划分方式和是否自行加噪。

不建议优先使用 DNS Challenge、完整 Free Music Archive、较大的 VoiceBank 训练包等大型数据集作为课程实验默认数据源。这些数据集下载和处理成本较高，不适合作为本实验的统一推荐。若学生确实使用大型数据集，应只取小规模子集，并在报告中说明。

## 5. 推荐模型

推荐使用以下深度学习模型：

- U-Net Spectrogram Denoising：在频谱图上进行去噪，结构直观。
- Conv-TasNet：时域音频分离和增强模型。
- Demucs：常用于音乐源分离，也可作为音乐增强参考。
- Denoiser：预训练语音去噪模型，适合快速完成推理实验。
- RNNoise：轻量级实时语音降噪模型，适合工程展示。

如果使用开源代码或预训练权重，需要说明代码地址、模型版本和本组修改内容。

## 6. 最小运行流程

建议流程：

1. 寻找合适的公开数据集，准备训练数据（clean 和 noisy 成对音频）。
2. 统一音频格式，例如采样率、声道数和 wav 编码。
3. 选择一个深度学习模型或预训练模型。
4. 在自行准备的数据上运行推理。
5. 在固定验收测试音频 `test/raw.MP3` 上生成去噪结果。
6. 保存去噪音频、波形图和频谱图。
7. 对比不同方法的听感和指标。

## 7. 评价指标

可选定量指标：

- SNR：信噪比。
- SDR：信号失真比。
- PESQ：语音质量评价指标。
- STOI：语音可懂度评价指标。

可选定性评价：

- 噪声是否明显减弱
- 音乐或语音主体是否清晰
- 是否出现失真、闷音或机械感
- 高频细节是否被过度抹除
- 静音段是否残留噪声

如果没有干净参考音频，可以重点使用试听、波形图、频谱图和人工评价。

## 8. 报告建议

报告中建议说明：

- 音乐去噪任务的背景和应用
- 音频数据来源和预处理方式
- 模型结构或调用方式
- 实验环境和运行命令
- 波形图和频谱图对比
- 定量指标表格
- 成功案例和失败案例
- 小组分工和改进方向

## 9. 可扩展方向

可选扩展：

- 比较不同噪声强度下的去噪效果。
- 尝试不同采样率或不同音频类型。
- 分析语音去噪和音乐去噪的差异。
- 尝试训练小型 U-Net 或微调预训练模型。
