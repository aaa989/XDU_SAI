# 数据来源

## 图像恢复

固定验收测试图：`image_restoration/test/damaged/img_inpainting.jpg`，由课程提供。

## 音乐/语音去噪

固定验收测试音频：`music_denoising/test/raw.MP3`，由课程提供。

学生自行寻找合适的公开数据集用于训练。可参考：

- Microsoft MS-SNSD：https://github.com/microsoft/MS-SNSD
- VoiceBank-DEMAND：常用语音去噪基准数据集

## 吟诗作赋

chinese-poetry 开源诗词语料库已包含在 `poem_generation/chinese-poetry/` 中，包含唐诗、宋词、诗经、楚辞、论语等多种诗词文献，学生可直接使用。

- GitHub：https://github.com/chinese-poetry/chinese-poetry
