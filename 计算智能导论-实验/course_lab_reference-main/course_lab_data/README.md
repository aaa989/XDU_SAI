# 课程上机实验数据包

本数据包仅提供各任务的固定验收测试数据，供本地验收和结果展示使用。学生需要自行寻找合适的公开数据集用于训练和实验，并在报告中说明来源、规模和使用方式。

## 目录

- `image_restoration/test/damaged/img_inpainting.jpg`: 图像恢复任务固定验收测试图。
- `music_denoising/test/raw.MP3`: 音乐去噪任务固定验收测试音频。
- `poem_generation/chinese-poetry/`: 吟诗作赋任务提供的诗词语料库（chinese-poetry 开源项目），学生可从中获取训练数据。

## 使用方式

图像恢复：输入 `test/damaged/img_inpainting.jpg`，输出修复后图像。该图没有干净参考图，主要进行视觉质量评价。

音乐去噪：输入 `test/raw.MP3`，输出去噪后的音频。该音频为带噪音频，没有干净参考，主要进行主观听感和波形/频谱对比评价。

吟诗作赋：`chinese-poetry/` 提供了唐诗、宋词、诗经等诗词语料，学生可从中提取训练数据，并自行设计 prompt 进行生成实验。

## 说明

助教提供固定的验收测试数据和诗词语料库。训练数据和其他实验数据可由学生自行扩展。学生应在报告中说明数据来源、规模、使用范围和预处理方式。
