# 图像恢复任务参考

## 1. 任务目标

图像恢复（Image Restoration / Image Inpainting）任务要求根据受损或有缺失区域的输入图像，恢复出完整、清晰的图像内容。本次课程数据以古画修复为例，要求对存在划痕、污渍、遮挡或区域缺失的图像进行修复，尽可能还原原始画面。

学生需要使用深度学习模型完成图像修复任务，理解模型原理并分析修复效果。

## 2. 输入与输出

典型输入：

- 受损图像（含划痕、污渍、遮挡或区域缺失）

典型输出：

- 修复后的完整图像

建议展示形式：

- 输入受损图像
- 修复后输出图像
- 不同方法的对比结果
- 成功案例和失败案例分析

## 3. 数据准备

助教仅提供固定验收测试图 `test/damaged/img_inpainting.jpg`，没有对应的干净参考图，主要用于最终视觉质量评价。

学生需要自行寻找合适的公开数据集用于训练和实验。可以从以下方式获取训练数据：

- 下载公开图像数据集，自行合成损坏样本（添加划痕、遮挡、噪声等）。
- 使用已有的图像修复公开数据集。
- 自建小规模数据集。

训练数据应包含损坏图像和对应的干净参考图像，以便计算定量指标和训练模型。

```text
image_restoration/
  test/
    damaged/        # 固定验收测试图（助教提供）
```

## 4. 数据集建议

学生需要自行寻找合适的训练数据。以下是一些常用的公开数据集供参考：

| 数据集 | 规模参考 | 适用说明 |
|---|---:|---|
| Oxford-IIIT Pet | 约 770MB 到 800MB | 宠物图像，可自行合成损坏样本用于训练 |
| CelebA-HQ | 约数 GB | 人脸图像，常用于人脸修复实验 |
| Places2 | 约数十 GB | 场景图像，大规模，适合 inpainting 训练 |
| DIV2K | 约数 GB | 高质量图像，适合图像恢复类任务 |
| 自建小数据集 | 由学生控制 | 需要提供损坏图像和对应的干净参考图像 |

## 5. 推荐模型

推荐使用以下深度学习模型：

- U-Net：结构简单，适合课程实验，可用于端到端图像修复。
- Partial Convolution：NVIDIA 提出，专门处理不规则遮挡区域的修复。
- Contextual Attention（Globally & Locally）：利用图像上下文信息进行修复。
- DeepFill v1/v2：常用图像修复模型。
- Restormer：Transformer-based 图像恢复模型。
- 预训练扩散模型（如 Stable Diffusion Inpainting）：可直接调用进行修复，但需说明原理和调用方式。

如果使用开源代码或预训练权重，需要说明代码地址、模型版本和本组修改内容。

## 6. 最小运行流程

建议流程：

1. 寻找合适的公开数据集，准备训练数据（损坏图像和对应的干净参考图像）。
2. 选择并训练一个深度学习模型。
3. 在自行准备的数据上快速检查输入输出是否正确。
4. 在固定验收测试图 `test/damaged/img_inpainting.jpg` 上生成修复结果。
5. 保存修复后的图像。
6. 计算 PSNR、SSIM 等定量指标（在有 clean 参考的自行准备数据上）。
7. 分析成功和失败案例。

## 7. 评价指标

可选定量指标（需要有 clean 参考图时才能计算）：

- PSNR（Peak Signal-to-Noise Ratio）：峰值信噪比，衡量像素级重建质量。
- SSIM（Structural Similarity Index）：结构相似性，更贴近人眼感知。
- LPIPS（Learned Perceptual Image Patch Similarity）：基于深度特征的感知相似度。

可选定性评价：

- 修复区域是否自然融合，无明显边界
- 纹理和结构是否合理还原
- 整体视觉一致性
- 是否引入伪影或不合理的填充内容
- 不同方法的视觉对比

## 8. 报告建议

报告中建议说明：

- 图像恢复/修复任务的背景和应用
- 数据来源和损坏类型说明
- 模型结构或调用方式
- 实验环境和运行命令
- 修复结果对比图
- 定量指标表格（如有 clean 参考）
- 成功案例和失败案例
- 小组分工和改进方向

## 9. 可扩展方向

可选扩展：

- 比较不同深度学习模型的修复效果。
- 分析不同损坏类型（划痕、遮挡、噪声）对修复效果的影响。
- 尝试数据增强，例如随机遮挡、不同损坏比例。
- 尝试后处理方法优化修复边界。
