# 吟诗作赋任务参考

## 1. 任务目标

吟诗作赋任务要求根据主题词、关键词、上句、风格要求或其他输入，生成符合语义和格式要求的诗词或短文。学生需要理解文本生成任务的基本流程，选择合适的数据集和模型，并分析生成文本的质量。

学生需要使用深度学习模型或中文预训练语言模型完成文本生成任务，重点是说明生成方法、设计评价标准，并展示不同输入下的生成效果。

## 2. 输入与输出

典型输入：

- 主题词
- 关键词
- 上句
- 风格要求
- 图片描述，可选

典型输出：

- 古诗
- 词
- 短文
- 其他符合任务要求的中文生成文本

建议展示形式：

- 输入 prompt
- 生成结果
- 多个模型或设置的对比
- 格式、语义和风格分析
- 人工评价表格

## 3. 示例数据准备

如果没有现成数据，可以先准备少量 prompt：

1. 选择若干主题，例如春雨、边塞、离别、月夜、江南。
2. 为每个主题准备关键词。
3. 设计不同输入形式，例如只给主题、给上句、给风格要求。
4. 使用模型生成结果。
5. 对生成结果进行人工评价和分析。

建议样例数量：

- 基础展示：5 到 10 个 prompt
- 较完整实验：50 到 200 个 prompt
- 数据集实验：使用公开诗词语料进行训练、微调或检索

## 4. 数据集建议

课程数据包已包含 chinese-poetry 开源诗词语料库（`poem_generation/chinese-poetry/`），包含唐诗、宋词、诗经、楚辞、论语等多种诗词文献，学生可直接用于训练和实验。

多数公开诗词数据是文本语料，不一定天然包含 prompt-response，因此需要学生自行设计固定 prompt 作为测试输入。

如果希望使用更多数据，可参考以下公开数据集：

| 数据集 | 规模参考 | 适用说明 |
|---|---:|---|
| chinese-poetry | 约 100MB 以内 | 常用中文诗词语料，包含唐诗、宋词等 |
| 全唐诗小规模整理版 | 通常小于 100MB | 适合五言、七言、绝句等格式控制实验 |
| 全宋词小规模整理版 | 通常小于 100MB | 适合词牌、风格生成实验 |
| 自建 prompt 与参考文本 | 由学生控制 | 可用于补充展示和人工评价 |

使用扩展数据时需要在报告中注明来源、规模、清洗方式、训练/测试划分和是否使用预训练模型。

不建议使用无法确认来源、无法下载或规模过大的文本集合。若只调用在线大模型生成文本，也需要准备一组固定 prompt 作为本地验收样例，并在报告中说明调用方式。

## 5. 推荐模型

推荐使用以下深度学习模型：

- Char-RNN：字符级循环神经网络，适合教学展示。
- LSTM：比简单 RNN 更稳定，适合小规模文本生成。
- Transformer Decoder：适合理解现代生成模型结构。
- GPT-2 Chinese：适合中文文本生成实验。
- 中文预训练语言模型：例如 Qwen、ChatGLM、Baichuan 等，需要说明调用方式和模型来源。

如果使用大模型 API 或本地大模型，需要在报告中明确说明，不应把纯调用结果当作从零训练结果。

## 6. 最小运行流程

建议流程：

1. 准备 prompt 样例。
2. 选择一个深度学习模型或预训练语言模型。
3. 使用相同 prompt 生成结果。
4. 整理不同方法的输出。
5. 从格式、语义、流畅性和风格一致性进行评价。
6. 分析成功和失败案例。

## 7. 评价指标

可选定量指标：

- BLEU：衡量与参考文本的 n-gram 重合程度。
- ROUGE：衡量与参考文本的覆盖程度。
- 困惑度：衡量语言模型对文本的建模能力。

可选人工评价维度：

- 语义相关性
- 语言流畅性
- 格式正确性
- 风格一致性
- 诗意或表达质量
- 是否存在重复、跑题或不通顺

对于开放式文本生成，人工评价和案例分析通常比单一自动指标更重要。

## 8. 报告建议

报告中建议说明：

- 文本生成任务的背景和应用
- 数据集来源和清洗方式
- prompt 设计方式
- 模型结构或调用方式
- 实验环境和运行命令
- 不同方法生成结果对比
- 自动指标或人工评价表格
- 成功案例和失败案例
- 小组分工和改进方向

## 9. 可扩展方向

可选扩展：

- 比较不同 prompt 设计对生成结果的影响。
- 比较不同深度学习模型的生成效果。
- 尝试控制诗词格式，例如五言、七言、绝句。
- 加入主题一致性或押韵约束。
- 分析大模型生成结果中的套话、重复和风格漂移问题。
