# 实验运行相关说明 📌

## 💻 实验运行设备 \& 数据集准备

* **实验1 \~ 5**：全程在开发板上运行就行✅
项目自带配套数据集，不用自己额外下载，保险起见，建议手动自己拷贝备份一份，避免出问题\~
* **实验6 \~ 7**：需要在自己的私人电脑上运行💻
数据集**必须自己提前备好**，项目没有自带哦！
* **实验7**：属于自定义自拟选题实验，仓库里就不附带相关代码和配套内容啦。

## ⏱️ 各实验运行耗时参考

* **实验1 \~ 4**：运行耗时不长⏳
正常情况大概10分钟左右就能跑完，耐心等一会儿就好。
* **实验5**：耗时偏久⚠️
运行时长大概30分钟，运行前提前预留好时间，不要中途中断程序。
* **实验6**：运行时间比较长🔥
训练epoch设置5\~10就完全够用；
纯CPU跑大概需要30分钟，用GPU加速的话会快很多，效率翻倍！

## ❗ 重点避坑提醒（必看）

跑实验6的时候，一定要核对好自己电脑的**CUDA版本**！

如果装的框架版本和CUDA版本不匹配，程序就会默认只用CPU单核运行，GPU完全用不上，白白浪费性能，跑起来又慢又白费功夫😫
